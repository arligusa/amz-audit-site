How to pull your Search Term Report
  1. Sign in at advertising.amazon.com (or Seller Central → Advertising → Campaign Manager).
  2. Go to Measurement & Reporting → Sponsored ads reporting → Create report.
  3. Report type: Search term report. Pull one for Sponsored Products and one for Sponsored Brands if you run both.
  4. Time unit: Summary (not Daily).
  5. Date range: last 30–60 days.
  6. Format: .csv or .xlsx, whichever Amazon offers.
  7. Download it as-is once it's ready (a few minutes, up to ~45 min for long ranges) — don't filter or resave it.
  8. Upload the file below. We can't start your PPC audit until we have it.

Older accounts: Campaign Manager → Bulk Operations → Download campaigns → Enabled & Paused → check Sponsored Products / Sponsored Brands search-term data.

Want a sharper report? Optional — everything below is skippable, the audit still runs without it.
How to copy your backend search terms
  1. Seller Central → Catalog → Manage All Listings (or Manage Inventory).
  2. Find this product → open the row's dropdown → Edit.
  3. Click the "More details" tab (some accounts label it "Keywords").
  4. Copy everything in the "Search terms" field and paste it below.

This is the single best way to close the biggest gap in a public-only scan — backend terms are invisible from the listing page, so we can only check them if you paste them here.

How to pull your Business Report
  1. Seller Central → Reports → Business Reports.
  2. Left sidebar, under "By ASIN" → Detail Page Sales and Traffic.
  3. Set the date range (top right) to the last 30 days.
  4. Click Download → choose .csv.
  5. Upload the file below.

Real traffic and conversion data for this exact ASIN — it grounds the findings in your actual numbers instead of estimates from the public page.
